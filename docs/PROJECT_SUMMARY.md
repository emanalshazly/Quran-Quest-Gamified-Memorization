# 📋 ملخص مشروع Quran Quest

> آخر تحديث لهذا الملخص يعكس الحالة الفعلية للكود في المستودع — بدون مبالغات.

## الحالة العامة

المشروع **قيد التطوير النشط** — الهيكل الأساسي الكامل (Backend + Database + Mobile) موجود ويعمل منطقياً، لكنه **ليس جاهزاً للإنتاج** بعد.

## ✅ ما تم إنجازه

### Backend (Node.js + Express)
- حوالي **40 API endpoint** عبر 8 مجموعات: auth, kids, surahs, memorization, gamification, battle, parent, notifications
- مصادقة عبر **Supabase Auth** (JWT) مع إنشاء صف `public.users` تلقائياً عند التسجيل
- عميلان لـ Supabase: anon للمصادقة، **service-role** لعمليات قاعدة البيانات (التحقق من الملكية يتم في الكود)
- خوارزمية **SM-2** للمراجعة المتباعدة (1 يوم / 6 أيام / الفترة × معامل السهولة)
- نظام نقاط **ذري** (SQL function) مع تحديث المستوى تلقائياً
- 8 شارات، و streaks، وتحديات يومية، وتحدي الإخوة (Battle Mode)
- حد ملفات الأطفال حسب الباقة (1/3/5) في الكود وفي trigger بقاعدة البيانات
- تجهيل أسماء الأطفال في اللوحة العالمية (خصوصية COPPA)
- Rate limiting + Helmet + CORS

### Database (PostgreSQL على Supabase)
- 13 جدولاً مع فهارس و triggers
- `users.id` مرتبط بـ `auth.users` مع trigger إنشاء تلقائي
- سياسات **RLS كاملة** لكل الجداول
- دوال SQL: `calculate_next_review` (SM-2)، `increment_kid_points`، `update_leaderboard`
- نص القرآن كاملاً: 114 سورة و6236 آية من مشروع تنزيل (Tanzil) مع رابط تلاوة لكل آية — انظر `database/README.md`

### Mobile (React Native 0.73)
- نقطة الدخول + App + Navigation (Stack + Bottom Tabs) كاملة
- **15 شاشة**: Login, Register, ForgotPassword, KidProfiles, Home (خريطة المغامرة بحالات: محفوظة ✓ ذهبية / حالية متوهجة / مقفلة 🔒), SurahDetail, Memorization (آية-آية مع تكرار وتشغيل صوتي), Test (تسجيل صوتي), Review (SM-2), Leaderboard (عائلي + عالمي), Badges, Battle, ParentDashboard, Settings
- Contexts: Auth + App (لغة، وضع ليلي، ملفات الأطفال)
- طبقة API كاملة مع Axios و interceptors

## 🚧 ما هو ناقص قبل الإطلاق

| البند | الحالة |
|------|--------|
| مجلدات ios/ و android الأصلية | غير موجودة — يلزم توليدها وربط المكتبات |
| فضائل السور | موجودة لـ 10 سور فقط — الباقي يحتاج نصوصاً من مصادر موثقة |
| تقييم التلاوة بالذكاء الاصطناعي (TFLite) | **غير مدمج** — التقييم الحالي placeholder والدرجات تأتي من العميل (تُقيَّد 0-100 في الخادم) |
| الإشعارات | تذكيرات المراجعة المحلية موجودة (انظر `docs/NOTIFICATIONS.md`)؛ الإشعارات الفورية من الخادم (FCM/APNs) غير موجودة |
| الاستماع للتلاوة دون اتصال | غير موجود (باقي العمل دون اتصال موجود — انظر `docs/OFFLINE.md`) |
| الاشتراكات داخل التطبيق (IAP) | غير موجودة (المنطق يعتمد على حقل subscription_tier فقط) |
| تدفق موافقة الوالدين (COPPA) | غير موجود |
| التقرير الأسبوعي بالبريد | غير موجود |
| الاختبارات الآلية | اختبارات وحدة لمنطق التذكيرات والعمل دون اتصال في الموبايل؛ لا اختبارات للـ Backend ولا للشاشات |
| Input validation شامل | أساسي فقط |
